# わたしの家計簿

自分のPCだけで使う、シンプルな家計簿です。

## 使い方

1. 金額、カテゴリー、日付、必要ならメモを入力します。
2. 「記録する」を押します。
3. 月を切り替えると、その月の合計・グラフ・履歴を確認できます。
4. 間違えた記録は、履歴の右端にある「×」で消せます。

記録はブラウザの中に自動保存されます。同じPCでも、別のブラウザには引き継がれません。ブラウザの保存内容を消すと家計簿の記録も消えるため、大切な記録を長く残す版では、次の段階で書き出し機能やデータベースを追加してください。

## 次回の起動

このフォルダで次を実行します。

```bash
pnpm run dev
```

表示された `http://localhost:3000/` をブラウザで開きます。止めるときは、起動した画面で `Ctrl + C` を押します。

## 主なファイル

- `app/page.tsx` — 家計簿の動きと画面の内容
- `app/globals.css` — 色、余白、スマホ向けの見た目
- `app/layout.tsx` — ブラウザに表示される名前
